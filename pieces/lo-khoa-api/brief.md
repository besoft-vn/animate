# Brief — "Lộ khoá API trong log AI agent: bài học từ vụ Cursor" (Besoft, 16/11/2026)

Source: https://besoft.vn/blog/lo-khoa-api-trong-log-ai-agent-bai-hoc-tu-vu-cursor — facts cross-checked in `research.md` (BleepingComputer, The Hacker News, Cursor's notice).

**Idea:** no complex exploit — a few keys in the wrong place, chained, became a supply-chain attack. **Device:** a RED KEY (`keyProp`) is the constant; it hops link to link along the attack chain; each link scene lights one more link in `chainStrip(n)` at the top. **End = start, changed:** the hook's chat box again, the key now masked "••••" (`keyProp(..., { masked: true })`), green check.

**Style:** crosshatch. Paper world (`paperSheet` or `woodSurface`) for people; navy (`darkWorld(key, { dust: 40 })` — keep dust low!) for systems. 9:16, 24 fps, 69 s, voice Tuan Khang.
